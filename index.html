Gerador de Link de Imagem

Faça o upload de uma foto para obter um link compartilhável instantaneamente.

Atenção: Configuração Necessária

Para o upload funcionar, você precisa de uma chave de API gratuita do imgbb.com. Edite este arquivo e cole sua chave na variável `API_KEY` dentro da tag <script> no final do código.
